# Lezione 12 — Prompt

## Prompt 1

Voglio smettere di ripetere il prompt per la specifica delle feature. Usa il tuo skill creator per aiutarmi a scrivere una skill locale "feature spec". Ecco il prompt precedente:

Trova la prossima fase in specs/roadmap.md e crea un branch, poi fammi domande sulla specifica della feature.
Crea:
 - Una nuova directory YYYY-MM-DD-nome-feature sotto specs per il lavoro su questa feature
 - Al suo interno:
  - `plan.md` come una serie di gruppi di task numerati.
  - `requirements.md` per perimetro, decisioni e contesto
  - `validation.md` per capire quando l'implementazione è riuscita e può essere unita (merge)

Fai riferimento a specs/mission.md e specs/tech-stack.md come guida.

Importante: *devi* usare il tuo strumento AskUserQuestion, raggruppando le domande su questi 3 file, prima di scrivere su disco.
